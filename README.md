# LLM翻译 Chrome插件

一个使用大语言模型进行翻译的Chrome浏览器插件。

## 功能特点

- 使用大模型API进行高质量翻译
- 中英文互译，自动判断语言类型
- 内置 Bing 翻译免费接口，无需 API Key，装上即可用
- 支持国内外主流大模型：DeepSeek、通义千问、智谱 GLM、OpenAI、Google Gemini，及自定义 OpenAI 兼容接口
- 整页翻译默认忽略页头/页脚，可在「翻译设置」中配置忽略的区域（导航、侧边栏、表单、弹窗等）
- 划词翻译：选中网页文字后自动弹出翻译按钮，可在「翻译设置」中开关，并通过横向/纵向偏移微调按钮位置，避免与其他插件的按钮重叠
- 右键菜单一键「翻译此网页」
- 可自定义API和模型配置

1. 下载本项目代码
2. 打开Chrome浏览器，输入 `chrome://extensions/`
3. 开启右上角的"开发者模式"

6. 安装完成后，可在浏览器右上角找到插件图标

## 使用说明

### 配置API密钥

1. 点击浏览器右上角的插件图标，打开弹出窗口
2. 默认使用 Bing 翻译（免费，无需 API Key）
3. 如需使用大模型，进入「模型设置」，选择服务商并填写模型 ID 与 API Key
4. 点击「保存配置」；已存在的「服务商 + 模型 ID」会自动更新，新组合会自动新增

### 翻译方式

支持三种翻译方式：

1. **选择文本翻译**：在网页上选择文本后，会自动出现"翻译"按钮（可在「翻译设置」中开关，或通过横向/纵向偏移微调按钮位置）
2. **右键菜单翻译此网页**：在页面上点击右键，选择「翻译此网页」即可整页翻译
3. **弹窗输入翻译**：点击插件图标，在弹出窗口中输入文本并点击"翻译"

### 支持的模型

- **Bing 翻译**（默认，免费）：使用微软 `edge.microsoft.com` 免费接口，无需 API Key，覆盖弹窗文本翻译、选中/右键翻译与整页翻译
- **DeepSeek**：`deepseek-v4-flash`
- **通义千问**：`qwen3.6-flash`
- **智谱 GLM**：`glm-4.7-flash`
- **OpenAI**：`gpt-5-mini`
- **Google Gemini**：`gemini-3-flash-preview`
- **自定义**：任意 OpenAI Chat Completions 兼容接口

在「模型设置」中，选择服务商并填写模型 ID 与 API Key；保存时按「服务商 + 模型 ID」自动新增或更新配置。

## 故障排除

如果您在使用插件时遇到问题，可以尝试以下方法：

### 1. 检查API连接

在「模型设置」中填写配置后，点击「测试连接」即可验证接口、密钥与模型是否可用。

### 2. 检查控制台日志

如果翻译不工作，可以查看浏览器控制台日志：
1. 在Chrome中右键点击插件图标，选择"审查弹出内容"
2. 切换到"控制台"标签
3. 查看是否有错误信息

### 3. 常见问题

- **翻译按钮不出现**：确保内容脚本已正确加载，并检查控制台是否有错误
- **API请求失败**：检查API密钥和端点是否正确，网络是否正常
- **翻译结果不显示**：检查数据解析部分是否有错误，不同模型的响应格式可能不同

### 图标生成

在使用插件前，需要生成PNG格式的图标。您可以使用在线SVG到PNG转换工具，将images目录下的SVG文件转换为相应大小的PNG图标。

## 免费翻译说明

- **Bing 翻译**：内置免费翻译接口，无需 API Key，安装后即默认使用，可直接翻译。
- 其他大模型（DeepSeek、通义千问、智谱、OpenAI、Gemini 等）需要您在各服务商官网申请自己的 API Key，填入「模型设置」中使用。
